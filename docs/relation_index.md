# Relation Index

## Core Structural Relations

### parent_of
Defines genealogical or generative descent.

Example:
Osiris -> parent_of -> Horus

---

### spouse_of
Defines marital/consort relationships.

Example:
Isis -> spouse_of -> Osiris

---

### sibling_of
Defines sibling relationships.

---

## Identity Relations

### identified_with
Strong equivalence or direct identity.

Example:
Lucifer -> identified_with -> Devil

---

### syncretized_with
Historical fusion.

Example:
Amun -> syncretized_with -> Zeus

---

### cult_form_of
Local cult-specific manifestation.

Example:
Serapis -> cult_form_of -> Osiris

---

## Comparative Relations

### aligned_with
Structural, archetypal, or theological resonance.

Example:
Leviathan -> aligned_with -> Tiamat
