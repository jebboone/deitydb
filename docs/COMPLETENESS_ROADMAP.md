# DeityDB Completeness Roadmap

Systematic gap register for the goal: *completeness for the entire western religious canon.*
Produced from a seven-domain parallel audit against the live DB (v1.84.2 — 3,173 entities /
5,761 relationships / 362 sources / 96 traditions). Each tier lists the gap, rough new-entity
count, and priority. "Already deep — do not rebuild" findings are recorded so we don't re-do them.

Confirmed COMPLETE (do not rebuild): Greek/Egyptian/Mesopotamian/Roman/Etruscan cores;
Zoroastrian pantheon (53); the Gnostic families; the Ars Goetia 72; the **Shem HaMephorash 72**
(stored as type "Shem angel"); the Olympic Spirits 7; the 42 Assessors of Maat; the Kabbalistic
four worlds + sefirot; the cross-traditional abstraction spine (~65); Islamic angels & jinn;
the Twelve Imams / Fourteen Infallibles; the Ascended-Master roster at the Bailey/Blavatsky level.

## TIER 7 — Quality & connectivity (cheap, high-impact, little/no new roster)
- **Connectivity dead zones** — **Manichaean (32 entities, 0 edges)** and **Mandaean (31 entities, 0 edges)** are completely disconnected; wire their internal emanation graphs + cross-links (Manichaean Az ↔ Zoroastrian Az; Mandaean/Christian John the Baptist). Zurvan is also unlinked (the twin-birth myth).
- **Data quality** — normalize the 23 case-variant `entity_type` labels (God/god, Goddess/goddess, …); fill the **57 blank entity_types**; consider a controlled `entity_class` column over the free-text descriptor; unify the scattered realm-type labels.

## SCOPE-BOUNDARY — the "is it western?" calls (owner decides)
- **Afro-diasporic of the Americas** (Vodou lwa, Santería/Candomblé orishas) — strongest case; a dense Catholic-saint *reception network*. Include-with-care (publicly-attested figures + saint-mappings only; living/closed traditions).
- **Yoruba / Ifá root pantheon** — include only as the African *source nodes* the diaspora points back to, if the above is included.
- **Rastafari** — Jah, Haile Selassie, Babylon (→ existing Whore of Babylon). Low-volume, Abrahamic-derived, New-World. Recommend include.
- **Folk-Catholic saints of the Americas** — Santa Muerte, Maximón/San Simón, Jesús Malverde, San La Muerte. Clearly western/Catholic-derived vernacular. Include-with-care (label unofficial).
- **Pre-Columbian pantheons** (Aztec/Maya/Inca) — exclude the pantheons; include only the syncretism seams (Tonantzin → the existing Our Lady of Guadalupe).

### Rough total: ~550–700 new entities + several thousand edges across ~35–45 build cohorts.
Execution principle (standing rules): every cohort wires its entities into collective/family hubs
and cross-tradition `reception_of`/`equated_with` edges in the same pass; new traditions get
`tradition_profile` rows; homonyms get `entity_duplicate_review` on both sides; agents return JSON
only (never write the DB); each release is QA'd for 0 unsourced / 0 orphan / 0 rationale-less.
